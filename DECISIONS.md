# DECISIONS — вопрос → что выбрал → почему

1. **`node --test tests\` на Node 24 не принимает каталог** → добавлен `tests\index.js`, который подключает все `*.test.js` → команда из ТЗ работает без изменений.
2. **Шрифты Inter / JetBrains Mono** (в макетах подключаются из сети) → в приложении системные шрифты-запасные → ТЗ требует полностью офлайн, а из сети разрешён только `npx serve`.
3. **Модули ES (`type: module`)** → `package.json` без зависимостей только для типа модулей → иначе тесты на `node --test` не импортируют ESM.
4. **Система G-кодов B/C** → генератор циклов отказывается выводить код и показывает сообщение → таблица кодов B/C — справочные данные, по памяти не вношу (см. TODO_DATA.md); безопасней не выводить, чем вывести неверный цикл.
5. **Дуга G02/G03** → «против часовой» в плоскости (Z вправо, X вверх) = G03 для заднего держателя, зеркально для переднего → совпадает с макетом (G03 для R0.5 на уступе) и ТЗ.
6. **Фаска «длина × угол»** → длина откладывается по оси Z, угол — к оси, катет по радиусу = длина·tg(угол) → в ТЗ не уточнено; так принято в чертежах (2×45°).
7. **Диаметр под наружную резьбу** → показывается рекомендация D − 0.1·P с подписью «рекомендация» → ТЗ требует «диаметр под резьбу», но без формулы; значение подписано как рекомендация, а не как данные стандарта.
8. **Подвод G76/G92 по Z** → начало цикла по Z = Z0 + max(3·ход, 3 мм), по X — D+2 (наружная) / Ø отверстия−2 (внутренняя) → запас на разгон шпинделя и безопасный подвод.
9. **Многозаходная резьба** → отдельный вызов цикла на каждый заход, старт сдвинут по Z на шаг, F = шаг × заходы, показано предупреждение → G76 не имеет безопасной сквозной поддержки заходов; расчёт требует проверки на станке.
10. **Угол профиля G76** → допустимы только 0, 29, 30, 55, 60, 80 → иначе ошибка, вывод кода блокируется.
11. **G76: «R0.»** → во втором блоке явно выводится R0. (конусность нет) → явное значение безопаснее умолчания.
12. **Первый блок контура G71 после G00 X.. Z2.** → см. этап 2.
