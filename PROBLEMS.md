# PROBLEMS

Тестов, которые не удалось починить, нет: все тесты из ТЗ проходят, `.todo` не использовались.

Известные ограничения (не ошибки тестов):
- Проверено только в headless Chrome (рендер всех экранов, клики, скриншоты) и юнит-тестами. На телефоне и на станке не проверялось.
- Карманы MF (v0.3), синхронизация библиотеки с Google Drive, фото наладки, журнал в карточке по связи «деталь = название» (v0.7) не сделаны.
- Шрифты Inter/JetBrains Mono не подключены (офлайн): используются системные.
- Иконки PWA — один SVG; для установки на некоторых телефонах могут понадобиться PNG 192/512.
- Системы G-кодов B/C: циклы не выводятся (см. TODO_DATA.md).
